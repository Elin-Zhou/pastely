# PRODUCT_SENSE.md

> ⚠️ 初始版本：业务上下文来自用户原始需求描述（无外部 PRD 平台），待人工补充细化。

## 用户与场景

个人效率工具。用户在日常工作里频繁复制文本/截图，系统剪切板只保留最后一条，需要可回溯的历史。

## 核心需求（用户原话要点）

1. 保存**所有**历史复制到剪切板的内容
2. 内容类型：**文本 + 图片**
3. 可设置**失效周期**（条目 TTL，到期自动清理）
4. 支持**自定义快捷键**
5. 按下快捷键 → 屏幕**弹出最近剪切板内容**（居中弹窗）
6. 弹窗出现后**输入焦点直接在搜索输入框**
7. 输入即**模糊搜索**历史内容
8. （隐含）选中条目后回车 → 写回剪切板并粘贴/可粘贴

## 体验要点

- 快捷键唤起到可打字，延迟必须低（<300ms 目标）
- 搜索即时响应，无需回车触发
- 图片条目需缩略图预览

## 非目标（当前版本）

- 云同步、多设备
- 富文本/文件类型剪切板内容（仅文本+图片）
- Windows/Linux 支持（架构上不强依赖单平台 API，但当前只验证 macOS）
